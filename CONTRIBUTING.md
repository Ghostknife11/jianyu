# Contributing

Jianyu is at Concept Freeze v0.1 and early implementation. Contributions should first strengthen the entry-point, multi-ecosystem Discovery, Opportunity Gate, Diversity, Nothing, family-choice, and lightweight-feedback loop.

Before proposing implementation:

1. read `README.md`, `ARCHITECTURE.md`, `DATA-SCHEMA.md`, `SECURITY.md`, `PRIVACY.md`, and `MVP-PRD.md`;
2. use synthetic data only;
3. state whether a change belongs to Stable Core, Opportunity Engine, or Evolvable Edge;
4. document new data, network, consent, age-stage, deletion, and Graduation effects;
5. add or update schema, migration, extension-contract, and threat-model tests;
6. create an ADR for runtime choices, cryptography, persistence, sync protocols, breaking schema changes, or changes to Concept Freeze principles;
7. never collapse dynamic `WorldBriefProvider` services into declarative Packs;
8. explain how the change treats Nothing, child pull, caregiver pressure, sparse data, and Graduation.

Do not include real child/family information, provider keys, access tokens, private prompts, or copied opportunity content without a compatible license.

Documentation and code contributions are submitted under Apache-2.0 unless explicitly marked otherwise. Significant behavioral defaults should live in replaceable Policy, not be hidden in Core.
