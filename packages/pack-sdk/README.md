# Pack SDK

Validates and reads v0.1 declarative Packs. Dynamic World Brief behavior belongs to WorldBriefProvider, not Pack.

Automatic trigger matching is a conservative local supplement: a child's explicit refusal of any trigger term suppresses that Pack entry, while an independently positive child clause can still match. A plainly caregiver-led plan or external background alone is not child pull; a caregiver's own refusal is not re-attributed as the child's veto. This is bounded lexical handling, not natural-language understanding or a substitute for the child's choice.
